Bank Management System

A Python-based Bank Management System that simulates basic banking operations such as account creation, deposits, withdrawals, balance checking, and account management. The system supports Savings and Current accounts, enforces a minimum balance of ₹500, and prevents withdrawals that would reduce the balance below the required minimum. It also allows users to view all accounts and calculate simple interest for Savings Accounts using a fixed interest rate.

Features

- Create Savings and Current accounts
- Minimum balance requirement of ₹500
- Deposit money
- Withdraw money while maintaining the minimum balance
- Check account balance
- Display all accounts
- Calculate simple interest for Savings Accounts
- Prevent duplicate account numbers
